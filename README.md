💰 Project Expense Tracker (Python)
📌 About the Project

The Project Expense Tracker is a Python-based application designed to help users record, manage, and track their project-related expenses efficiently.

This application makes expense management easier by allowing users to maintain expense records, calculate total spending, and monitor project costs. It aims to provide a simple and organized way to manage project finances.

➕ Add new expenses.
